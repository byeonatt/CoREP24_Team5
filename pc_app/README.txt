[앱 실행 방법]

main.py를 실행하기 (경로: pc_app/main.py)



[모듈 연결 및 측정 방법]

우측 '연결' 버튼을 누름 -> Connection 창 열림
연결할 Com 포트, 속도 선택하고 연결 클릭 -> 연결 상태가 '연결 성공'으로 바뀜
우측 '측정 설정' 버튼을 누름 -> Setting 창 열림
외경/내경 모드를 선택하고 적용 클릭 -> 상태가 '상태 : 준비'로 바뀌고 '측정 시작'버튼이 활성화 됨
'측정 시작' 버튼을 누르면 측정이 시작됨
(측정 중, '측정 설정' 창에서 외경/내경 모드 변경, 영점 재설정 가능)
측정을 끝낸 후 '측정 종료' 버튼을 누르면 측정이 종료됨



[초기 저장 경로]

C:/Users/User/Documents/GripForceData



[MCU(ESP32 상정) 내장 파일 생성 프롬프트]

장비를 켠 순간부터 매 순간 측정 데이터를 터미널에 전송하는 시스템(별도의 시작, 종료 메세지 없음).
로드셀로부터 각각의 RAW 데이터를 받아서 내부에서 각각의 TARE_OFFSET, FORCE_FACTOR, DEADBAND 등을 이용해 N(뉴턴) 값으로 변화한 다음, 'F,(뉴턴값)' 형태로 출력한다. (예: F,12.3456)

명령어는 'CMD,(명령어)' 형태로 입력된다. (예: CMD,ZERO)

반응하는 명령어 목록
-ZERO -> 영점을 조절한다(TARE_OFFSET을 새로 지정한다).
-MODE_OD -> 외경 모드로 변환한다.
-MODE_ID -> 내경 모드로 변환한다.

외경 모드 : 외경 측정용 Force Factor를 각 로드셀의 RAW 값에 적용하여 LC1, LC2의 힘을 각각 N 단위로 계산한다.
내경 모드 : 내경 측정용 Force Factor를 각 로드셀의 RAW 값에 적용하여 LC1, LC2, LC3의 힘을 각각 N 단위로 계산한다.
