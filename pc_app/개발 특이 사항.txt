※ 개발 특이사항 ※

※ 본 프로젝트에서는 사용하지 않는 네 번째 차동 채널의 변환 과정을 제거하여 측정 주기를 단축하기 위해 ADS1256 라이브러리의 헤더 파일(ADS1256.h)과 구현 파일(ADS1256.cpp)을 수정하고, 3채널 전용 cycleDifferential3() 함수를 추가하였다. (기존 ADS1256 라이브러리에는 cycleDifferential3() 함수가 제공되지 않는다.)

※ ADS1256은 AIN0~AIN7의 총 8개 아날로그 입력을 제공하며, single-ended 방식에서는 최대 8개 입력을, differential 방식에서는 4개 입력 쌍을 사용할 수 있다. 본 장비에서는 AIN0-AIN1, AIN2-AIN3, AIN4-AIN5, AIN6-AIN7을 각각 하나의 차동 채널로 구성하며, 현재 이 중 3개 채널만 사용한다.

※ cycleDifferential3()은 현재 사용하는 3개의 차동 채널만 순환하도록 본 프로젝트에서 별도로 구현한 함수이다. 따라서 추후 네 번째 차동 채널(AIN6-AIN7)까지 사용할 경우에는 cycleDifferential3()을 4채널용으로 수정하거나, 기존 cycleDifferential()을 사용하거나, 필요에 따라 setMUX()와 readSingle()을 이용해 채널을 직접 선택하여 측정해야 한다. 기존 cycleDifferential()은 4개의 차동 입력 쌍을 순차적으로 순환한다.

※ 함수 ※
setMUX()
→ ADC가 측정할 입력 조합을 선택하는 함수이다. 예를 들어 DIFF_0_1, DIFF_2_3, DIFF_4_5, DIFF_6_7 등의 차동 입력 조합을 선택할 수 있다. 현재 사용하는 ADS1256 라이브러리의 setMUX() 함수는 MUX 레지스터를 변경한 후 delay(200)을 수행하므로, 여러 채널을 빠르게 반복 순환하는 용도에는 적합하지 않다.

readSingle()
→ 현재 MUX로 선택된 입력 채널의 변환값을 한 번 읽는 함수이다. ADS1256의 RDATA 명령을 사용한다.

readSingleContinuous()
→ 현재 선택된 하나의 입력 채널을 연속적으로 읽는 함수이다. RDATAC 명령을 사용하므로 하나의 채널을 지속적으로 빠르게 측정할 때 사용할 수 있다. 다른 측정 방식으로 전환하려면 연속 변환을 종료하는 처리가 필요하다.

cycleSingle()
→ AIN0~AIN7을 각각 AINCOM과 조합한 8개의 single-ended 입력을 순차적으로 측정하는 함수이다. 즉 AIN0-AINCOM → AIN1-AINCOM → ... → AIN7-AINCOM 순으로 순환한다.

cycleDifferential()
→ AIN0-AIN1 → AIN2-AIN3 → AIN4-AIN5 → AIN6-AIN7의 4개 차동 입력을 순차적으로 측정하는 함수이다. 본 프로젝트의 cycleDifferential3()은 이 함수에서 사용하지 않는 네 번째 차동 입력을 제외하도록 수정한 3채널 전용 방식이다.
